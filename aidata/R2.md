# Project Overview – Information System

---

## 1. What This Product Is

* A **personal information system**
* Built for **one user per instance**
* Web-based, password-protected
* Self-owned data, closed-source software
* Designed to **capture first, organize later**
* Optimized for **thinking, remembering, rediscovering**

---

## 2. Core Philosophy

* **Input > Structure**
* **Raw data is sacred**
* **No forced organization**
* **No cognitive load at capture time**
* **AI assists, never controls**
* **Visual memory over lists**

---

## 3. What a “Post” Is

* A **Post = one unit of information**
* Created when user submits anything
* Can contain:

  * Text
  * Images
  * Audio
  * URLs
  * Mixed content
* Stored **exactly as provided**
* Never modified by AI
* User edits create versions, not overwrites

---

## 4. Home Page (Capture Surface)

* Black screen
* One central input box
* Purpose:

  * Only to **put information**
* No:

  * Search
  * Tags
  * Metadata
  * Navigation
* User action:

  * Paste / drop / type
  * Submit
  * Done

This page is **frictionless and silent**.

---

## 5. How Data Flows

1. User submits content
2. System stores:

   * Raw data
   * Timestamp
   * Source (web, mobile, extension)
3. Post becomes immutable source
4. Any future actions reference this post

---

## 6. Derived Data (Important)

Derived data is **never the source**.

Derived items include:

* Tasks
* Reminders
* AI tags
* AI descriptions
* AI summaries

Rules:

* Always link back to original post
* Can be deleted without affecting post
* Can be regenerated
* Optional

---

## 7. Infinite Canvas (Main Exploration Space)

* Second main screen
* Infinite 2D / 2.5D space
* No headers
* No menus
* No UI chrome
* Content **is the interface**

---

## 8. Canvas Mental Model

* Feels like:

  * Pinboard
  * Pinterest
  * Memory map
  * Zoomable globe
* User views a **window into a large space**
* Scroll = pan
* Zoom = depth / time / density

---

## 9. How Posts Appear on Canvas

* Automatically placed
* Based on:

  * Time created
  * Content similarity
  * User interaction
* No manual layout required
* User can rearrange if desired

---

## 10. Zoom Levels Meaning

### Zoomed Out

* Dense clusters
* Abstract shapes
* No readable text
* Shows:

  * Activity periods
  * Topic density

### Mid Zoom

* Card previews
* Images visible
* Snippets visible
* Pinterest-like browsing

### Zoomed In

* Full content
* Edit actions
* Task/reminder links

---

## 11. Search (Only on Canvas)

* No search on home page
* Search overlays the canvas
* Search behavior:

  * Highlights matching posts
  * Zooms/pans to relevant areas
  * Dims unrelated content
* Clearing search restores canvas

---

## 12. Search Principles

* Deterministic first
* Meaning-based second
* Works on:

  * Raw text
  * OCR
  * Audio transcripts
  * Time phrases
* No visible tags needed

---

## 13. Tasks & Reminders

* Not created as standalone objects
* Always derived from posts
* Created by:

  * User selection
  * Optional AI suggestion
* Stored as references:

  * Source post remains unchanged
* Clicking a task opens the post

---

## 14. AI Role (Secondary)

* AI is **optional**
* Controlled via `.env`
* Can be fully disabled
* Uses third-party API (GROQ)

AI can:

* Suggest tags
* Suggest descriptions
* Power a chat/search page

AI cannot:

* Edit posts
* Delete data
* Create structure without approval

---

## 15. AI Chat / Search Page

* Separate page from canvas
* Chat-based interface
* Uses user’s own data
* Can answer:

  * “What did I save about X?”
  * “Summarize my notes on Y”
* Always references source posts

---

## 16. Devices & Access

### Mobile App

* Purpose: **Capture**
* Uses system “Share to App”
* Supports:

  * Text
  * Images
  * Links
  * Audio
* Pushes data to server
* Uses queue if offline

---

### Desktop (PC)

* Web app
* Primary place for:

  * Canvas
  * Search
  * Exploration
* Drag & drop supported

---

### Browser Extension

* One-click capture
* Saves:

  * Page
  * Selection
  * Images
* Sends raw data to system

---

## 17. Hosting Model

* One VPS per user
* Vendor-managed
* User-accessed via web + password
* No accounts
* No email
* No SaaS multi-tenancy

---

## 18. Authentication

* Single password
* Local-only
* No third-party auth
* Simple and private

---

## 19. Data Storage Model

* Dual storage:

  * Embedded database
  * File system copy
* Benefits:

  * Fast queries
  * Human-readable export
  * No fear of DB corruption
* User can export anytime

---

## 20. Performance Goals

* Designed for:

  * 1 CPU
  * 2 GB RAM
* Heavy visuals handled on client GPU
* Server focuses on:

  * Storage
  * Search
  * AI proxying

---

## 21. What This Product Is NOT

* Not a notes app
* Not a todo app
* Not a dashboard
* Not a social tool
* Not AI-first
* Not collaborative by default

---

## 22. Who This Is For

* Thinkers
* Writers
* Researchers
* Builders
* People who capture a lot
* People who hate organizing

---

## 23. Core Value

* Capture without thinking
* Never lose context
* Rediscover ideas visually
* Trust your data is safe
* Let structure emerge naturally

---

## 24. One-Line Identity

> **A personal, visual information system where you dump everything and find it later without effort.**
