AI Workflow (MD-Based, Production)
Goal

Use AI for coding assistance

Reduce repeated mistakes

Enforce rules via markdown

Keep humans in control

Folder Structure (Recommended)
/ai/
 ├─ claude.md
 ├─ rules.md
 ├─ architecture.md
 ├─ agents/
 │   ├─ backend.md
 │   ├─ frontend.md
 │   ├─ canvas.md
 │   ├─ ai.md
 │   └─ infra.md
 ├─ prompts/
 │   ├─ code.md
 │   ├─ refactor.md
 │   ├─ debug.md
 │   └─ review.md
 └─ mistakes.md

claude.md (MOST IMPORTANT)

Purpose:

Persistent memory for Claude

Rules Claude must always follow

Contents:

Project summary

Hard constraints

Tech stack (locked)

Things Claude must NOT do

Known mistakes Claude made earlier

Example:

# Claude Rules

- Backend is Express.js only
- Frontend is Svelte + Canvas/WebGL
- No React suggestions
- No DB other than SQLite/DuckDB
- No SaaS assumptions
- Always assume 1c / 2GB VPS


Claude reads this every time.

rules.md (Engineering Rules)

Purpose:

Coding standards

Architectural boundaries

Examples:

No blocking code in Express

No AI modifying source data

No frontend DB logic

All features must be toggleable via .env

architecture.md

Purpose:

Single source of truth for system design

Includes:

Data flow

API boundaries

DB usage rules

AI isolation rules

AI must follow, not redesign.

/agents/*.md (Role-Based AI)

Each file = one AI “persona”

Examples
backend.md

Express patterns

DB access rules

Performance constraints

frontend.md

Svelte patterns

Canvas rules

No DOM-heavy rendering

canvas.md

Coordinate system

Zoom/pan logic

No UI state inside render loop

ai.md

GROQ usage

Prompt safety

.env toggles

/prompts/*.md (Reusable Prompts)

Purpose:

Consistent instructions

No retyping prompts

Examples:

code.md → generate code

refactor.md → clean code

review.md → audit for bugs

debug.md → trace issues

mistakes.md

Purpose:

Log real AI mistakes

Prevent repetition

Examples:

Suggested React ❌

Broke immutability rule ❌

Added cloud auth ❌

Claude must read this and avoid repeats.

How You Use This (Workflow)

Update architecture.md when decisions change

Add mistakes to mistakes.md

Claude reads:

claude.md

rules.md

relevant agent/*.md

Use prompt from /prompts

Review output

Add new mistakes if needed

Why This Works

AI gets memory

No repeated explanations

Fewer hallucinations

Faster iteration

Enterprise-grade discipline

Final Principle

MD files = AI brain

Code = human-owned

AI assists, never decides
