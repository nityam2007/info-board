# Implement: DB Query

> Small task: Write ONE database query/operation.

## When to Use

- Adding new query
- Optimizing existing query

## Template

```
Operation: [SELECT/INSERT/UPDATE/DELETE]
Table: [table name]
DB: [SQLite or DuckDB]

Purpose: [what data to get/modify]

Filters: [conditions]
Joins: [if any]
Index: [needed?]
```

## Output Expected

- SQL query or ORM call
- With parameterization
- Async wrapper
