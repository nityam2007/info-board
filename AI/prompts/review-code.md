# Review: Code Check

> Small task: Review ONE file or function.

## When to Use

- Before merge
- After implementation
- Security audit

## Template

```
Review: [file or function]

Check for:
- [ ] Follows rules.md
- [ ] Follows architecture.md
- [ ] Not in mistakes.md
- [ ] Async/non-blocking
- [ ] Error handling
- [ ] Input validation
```

## Output Expected

- Pass/Fail per check
- Issues list (if any)
- Fix suggestions
