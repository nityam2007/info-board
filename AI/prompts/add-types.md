# Add: Type Definition

> Small task: Add TypeScript types for ONE interface/module.

## When to Use

- New data structure
- API contract
- Shared types

## Template

```
For: [module/feature name]
Location: [types file]

Define types for:
- [entity 1]
- [entity 2]

Related: [existing types to extend]
```

## Output Expected

- Type/interface definitions
- JSDoc if needed
- Export for reuse
