# Plan: Break Down Task

> Small task: Create step-by-step plan before executing.

## When to Use

- Multi-step features
- Complex changes
- Before any implementation

## Template

```
Task: [describe what needs to be done]

Break this into small steps:
1. Each step = 1 small change
2. Each step = verifiable
3. Order by dependency

Output: Numbered list of steps
```

## Output Expected

- Numbered steps (max 5-7)
- Each step is atomic
- No code yet
