# Analyze: Read & Understand

> Small task: Read and understand before acting.

## When to Use

- Starting any new task
- Before writing any code
- When context is unclear

## Template

```
Read these files:
- [file1]
- [file2]

Tell me:
1. What does this code do?
2. What are the key functions/components?
3. What are the dependencies?
```

## Output Expected

- Bullet point summary
- No code changes
- Questions if unclear
