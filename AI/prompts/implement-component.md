# Implement: Svelte Component

> Small task: Create ONE Svelte component.

## When to Use

- Adding new UI element
- Modifying component behavior

## Template

```
Component: [ComponentName.svelte]
Purpose: [what it renders]

Props:
- [prop]: [type]

State:
- [state]: [type]

Events:
- [event]: [when fired]

Styling: [minimal/scoped CSS]
```

## Output Expected

- Single .svelte file
- Props typed
- Minimal DOM
- Scoped styles
