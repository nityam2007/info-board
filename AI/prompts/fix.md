# Fix: Single Bug

> Small task: Fix ONE specific bug.

## When to Use

- Known bug with reproduction
- Error with stack trace

## Template

```
Bug: [description]
File: [location]
Error: [message or behavior]

Steps to reproduce:
1. [step]
2. [step]

Expected: [correct behavior]
Actual: [wrong behavior]
```

## Output Expected

- Root cause explanation
- Minimal fix (smallest change)
- No refactoring
