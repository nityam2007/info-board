# Test: Single Function

> Small task: Write test for ONE function.

## When to Use

- After implementing function
- Before refactoring

## Template

```
Function: [name]
File: [path]

Test cases:
1. [happy path]
2. [edge case]
3. [error case]

Mock: [what to mock]
```

## Output Expected

- Test file or test block
- Clear assertions
- Fast execution
