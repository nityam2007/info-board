# Implement: API Endpoint

> Small task: Create ONE Express route handler.

## When to Use

- Adding new endpoint
- Modifying endpoint behavior

## Template

```
Endpoint: [METHOD /path]
Purpose: [what it does]

Request:
- Body: [schema]
- Query: [params]

Response:
- Success: [schema]
- Error: [codes]

DB: [which db and tables]
```

## Output Expected

- Route handler only
- Input validation
- Error handling
- Async/await
