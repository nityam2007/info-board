# Refactor: Single Function

> Small task: Clean up ONE function without changing behavior.

## When to Use

- After feature works
- Code smell identified
- Performance issue

## Template

```
Target: [function name]
File: [path]
Issue: [what's wrong]

Goal: [cleaner/faster/readable]

Constraint: Same behavior, same tests pass
```

## Output Expected

- Refactored function
- Brief explanation
- No new features
